Student Performance EDA Using Python

Project Overview

This project performs Exploratory Data Analysis (EDA) on student performance data using Python. It explores the relationships between study hours, attendance, assignment scores, and exam marks through statistical analysis and visualizations.

Objectives

- Analyze student performance data.
- Explore the relationship between study hours and exam marks.
- Study the impact of attendance and assignment scores on exam marks.
- Visualize data using graphs and a correlation heatmap.
- Categorize students into Low, Medium, and High performance levels.

Dataset

The sample dataset contains 20 student records with the following columns:

- "Student_ID"
- "Study_Hours"
- "Attendance"
- "Assignment_Score"
- "Exam_Marks"
- "Performance_Level" (derived during analysis)

Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

Key Findings

- Average study hours: 5.30
- Average attendance: 77.15%
- Average assignment score: 65.65
- Average exam marks: 63.60
- Highest exam marks: 96
- Lowest exam marks: 35
- Missing values: 0
- Duplicate rows: 0

Assignment scores showed the strongest positive correlation with exam marks in this sample.

Visualizations

The notebook includes graphs for:

- Study Hours vs Exam Marks
- Distribution of Exam Marks
- Attendance vs Exam Marks
- Assignment Score vs Exam Marks
- Correlation Heatmap
- Students by Performance Level

How to Run

1. Download or clone this repository.
2. Open "Student_Performance_EDA.ipynb" in Jupyter Notebook or VS Code.
3. Install the required libraries if needed:
   "pip install pandas matplotlib seaborn"
4. Run the notebook cells in order.

Project Files

- "Student_Performance_EDA.ipynb" — analysis and visualizations
- "student_performance_eda.csv" — dataset
- "Student_Performance_EDA_Project_Report.docx" — project report

Conclusion

This exploratory analysis shows positive relationships between study hours, attendance, assignment scores, and exam marks in the constructed sample. Since the dataset is small, these findings should not be generalized to all students or interpreted as proof of causation.
